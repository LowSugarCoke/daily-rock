Current Redesigned New screen

Give the app a home, and surface the history it already tracks.

Today the product is a single orphan card with no navigation. The backend just shipped a full /history API (era, artist, genre filters) that has no UI yet. This redesign adds an app shell, refines the daily rating flow, and builds the History screen so the "systematic tracking" promise in the tagline is actually visible.

1

Add a shell, not just a card

A persistent Today / History nav replaces the single floating card so the app reads as a product, not a demo.

2

Make the log the payoff

History becomes the reward for rating daily — stats + filterable timeline turn logging into a visible streak.

3

Keep the visual language

Same red accent, same neutral card system already committed as "premium light mode" — refined, not replaced.

Design notes
  1. 1Stats strip is computed client-side from the same HistoryItem[] the list renders — no new backend fields required.
  2. 2Filter chips map 1:1 to HistoryQuery { era, artist, genre }; search is a client-side title/artist filter layered on top.
  3. 3Rows reuse the era/genre tag components from the Today card so the two screens feel like one system.
